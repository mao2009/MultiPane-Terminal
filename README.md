# MultiPane Terminal

Windows 向けの省メモリ・自由分割ターミナルを検討するプロジェクトです。

> **現在は技術調査段階です。** 実装方式、使用言語、エンジン、ライセンスは未確定です。既存ソフトだけで要求を満たせれば、このリポジトリでの新規開発は行いません。

## 必須要件
- 自由な再帰的縦横分割
- **各ペインが独立した複数タブを持つ**（ウィンドウ → 分割ツリー → ペイン → タブ）
- 各タブの独立したシェルセッション。非表示でも入出力・プロセスを維持
- PowerShell / cmd / WSL を想定、IME・Unicode・VT表示が動作
- Windows 10/11、軽量・低アイドル負荷
- テレメトリー・アカウント連携・常駐サービスなし

## 開発しない判断も歓迎
1. 既存製品を無改造で利用できるか検証する
2. 既存OSSの設定・拡張で可能か検証する
3. 不足部分だけを既存OSSへ追加（上流貢献/フォーク）する
4. 最後の手段として既存エンジンを使った独自ホストを作る

**特定言語・GUIフレームワーク・エンジンの採用は決め打ちしません。** 候補と評価の進め方は [調査計画](docs/research/oss-candidates.md)、[設計原則](docs/architecture/principles.md)、[計測計画](docs/performance/benchmark-plan.md) に記録します。

## 非目標（初期）
- 独自VTパーサ/ターミナルレンダラーの全面再実装
- 独自シェル、アカウント同期、AIエージェント機能の組み込み
- 実測なしの「最軽量」表明

## 開発開始ゲート
要求の適合性、OSS再利用・ライセンス、保守状況、実機メモリ/CPU測定、変更工数を比較し、選定理由をADRとして記録してから実装を始めます。
